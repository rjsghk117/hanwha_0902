# Python Logic 이해하기

## Python은 위에서 아래로, 한 줄씩 순서대로 실행
* 코드는 소설책 읽듯이 위에서 아래로 진행 된다.
* 각 줄이 끝나야 다음 줄로 넘어간다.
* `변수`를 사용하기 전에 **반드시** 선언(할당)해야한다.

**EXAMPLE**

```python
print(x)
x = 5
```
**결과**
```
NameError: name 'x' is not defined
```
컴퓨터는 전체를 읽고 파악하는 것이 아니라 위에서 아래로 순차적으로 읽는다.

## 변수는 "상자"가 아니라 "이름표"
대부분 `Python`을 상자에 비유하지만, 변수가 값에 붙이는 `이름표(라벨)`에 더 가깝다.

**EXAMPLE**
```python
x = [1, 2, 3, 4]
y = x   # y는 같은 리스트를 가리키는 또 다른 이름표
y.append(5)
print(x)
```
**결과**
```
[1, 2, 3, 4, 5]
```
* `y = x`는 복사가 **아니라** 같은 대상에 이름표를 하나 더 붙인 것이다.
* 그래서 `y`를 건드리면 `x`도 같이 바뀐다.

## 들여쓰기(indent)는 "이 코드는 여기 소속이다"라는 뜻

**EXAMPLE**
```python
if x > 0:
    print("양수")   #if에 속함
    print("확인")   #if에 속함
print("끝") # if밖, 항상 실행
```
* 들여쓰기가 같은 줄들을 하나의 `블록(block)`으로 묶인다.
* 중괄호`{}` 대신 들여쓰기로 **이 코드가 어디에 속하는지** 표시하는 것이다.

## 조건문 = 갈림길, 반복문 = 되돌아가기
* `if`는 조건이 `참(True)`이면 그 블록만 실행하고 지나간다 → **한번만** 결정
* `while/for`는 조건이 `참(True)`인 동안 **같은 블록을 계속 반복** → 매번 조건을 다시 확인
```python
i = 0
while i < 3:
    print(i)
    i += 1      #이 줄이 없으면 무한루프
```
**결과**
```
0
1
2
```
**중요**
`while`을 볼 때는 "이 조건이 언제 거짓(False)가 되는가?"를 먼저 찾아보는 습관이 중요하다. 그것이 안 보이면 무한루프이다.

## 함수는 코드를 나중에, 여러 번 쓰기 위해 포장해두는 것
**BAD EXAMPLE**
```python
def add(a, b):
    return a + b   
```
위의 예시를 보면 함수를 `정의`만 한 거지 `실행`을 한게 아니기 때문에 `아무것도 출력하지 않는다.` 마치 `설명서`만 만들고 실행을 한건 아니다.

**GOOD EXAMPLE**
```python
def add(a, b):
    return a + b

result = add(2, 3)
print(result)
```
**결과**
```
5
```
`result = add(2, 3)`에서 `add(2, 3)`이라고 **호출**하는 순간:
* `a` 자리에 `2`가 들어가고
* `b` 자리에 `3`이 들어가고
* 함수 안의 `return a + b`가 실행돼서 `2 + 3 = 5`가 계산되고
* `5`라는 값이 `result`라는 변수에 저장됀다.
